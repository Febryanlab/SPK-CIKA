# SPK Cika Mulia Multimedia

Sistem Pendukung Keputusan Pengelompokan Wilayah Pengiriman Voucher Fisik
menggunakan metode TOPSIS.

## Login Default
- Username: admin
- Password: admin123

## Cara Install
1. Copy folder `spk-cika` ke `C:\xampp\htdocs\`
2. Start Apache + MySQL di XAMPP
3. Buka `http://localhost/phpmyadmin`
4. Import file `database/spk_cika.sql`
5. Akses `http://localhost/spk-cika/`
6. Login dengan `admin` / `admin123`

## Fitur
- Login multi-user
- CRUD Pelanggan, Voucher, Kategori Kirim
- Kriteria & Bobot TOPSIS
- Penilaian Massal
- Hitung TOPSIS otomatis
- Detail Perhitungan Step-by-Step
- Grafik Chart.js
- Peta Google Maps
- Export PDF & Excel
- PWA (Installable)
